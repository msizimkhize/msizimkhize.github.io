# Portfolio

- `index.html`: page structure (rarely needs editing)
- `js/config.js`: **edit this**: name, links, location, experience, projects, skills
- `js/main.js`: builds the page from the config
- `css/style.css`: styling
- `assets/images/profile.png`: your round portrait (optional; hidden if missing)

Open `index.html` in a browser to preview. To publish, push this whole folder to a GitHub repository and enable GitHub Pages.
